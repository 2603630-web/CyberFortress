# Member 1 — Frontend Developer & UI/UX Designer

**Project Name:** CyberFortress  
**Role:** Frontend Developer & UI Designer  

---

## 1. Primary Responsibility
Website design and frontend development, ensuring a professional cybersecurity theme, intuitive user interactions, responsive layouts, and specific frontend modules.

---

## 2. Assigned Tasks
1. **Homepage Design:** Design and build the CyberFortress homepage, hero section, and feature cards.
2. **Navigation System:** Create the persistent navigation bar, header, footer, and shared website layout/shell.
3. **Password Checker Frontend:** Develop the Password Security Checker user interface and client-side evaluation display.
4. **Interactive UI:** Implement frontend interactions, dynamic UI logic, and state management using JavaScript/TypeScript.
5. **Responsive Design:** Ensure the website and all views are fully responsive across desktop, tablet, and mobile browsers.
6. **MFA Demonstration Logic:** Build the interactive frontend components and step-by-step UI logic for the Multi-Factor Authentication (MFA) demonstration module.

---

## 3. Deliverables
- Homepage / Landing page component.
- Navigation system and layout shell.
- Password Security Checker frontend module.
- Interactive UI components and dynamic state handlers.
- Responsive website design verification.
- MFA demonstration frontend logic and step-by-step user flow.
