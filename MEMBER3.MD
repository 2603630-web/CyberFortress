# Member 3 — Phishing Simulator, SOC Analytics, CTF & Documentation Developer

**Project Name:** CyberFortress  
**Role:** Phishing Simulator, Analytics & CTF Developer  

---

## 1. Primary Responsibility
Phishing awareness simulation development, threat vector design, security analytics, Chart.js visualizations, CTF challenges, scoring integration, and project technical documentation.

---

## 2. Assigned Tasks
1. **Phishing Simulator Frontend:** Develop the interactive Phishing Awareness Simulator user interface and email inspection view.
2. **Error Handling:** Implement robust client-side and feedback error handling for simulations and submissions.
3. **Varied Attack Vectors:** Design and implement diverse phishing attack vectors (credential harvesting, urgent account warnings, CEO fraud, fake invoices).
4. **Red Flags Identification:** Embed identifiable technical red flags (spoofed domains, mismatched URLs) and psychological red flags (urgency, fear, authority pressure).
5. **Adaptive Difficulty Levels:** Implement progressive difficulty scaling across phishing simulations and challenges.
6. **Constructive Metrics & Ethical Boundaries:** Establish clear educational scoring metrics, instant feedback explanations, and strict educational disclaimers.
7. **Chart.js Visualization:** Develop interactive charts and graphs using Chart.js for security event analytics and alerts over time.
8. **Event Tables & Filters:** Build security event log tables with filtering capabilities by severity, status, and timestamp.
9. **CTF Challenges:** Develop beginner-friendly CyberFortress Capture The Flag (CTF) challenges (encoding, log analysis, quizzes).
10. **Scoring Integration:** Implement user score tracking and point award integration upon successful challenge completion.
11. **Technical Documentation:** Prepare comprehensive technical documentation, architecture diagrams, setup guides, and project screenshots.

---

## 3. Deliverables
- Phishing Awareness Simulator frontend module with error handling.
- Varied attack vector scenarios featuring technical and psychological red flags.
- Adaptive difficulty progression and constructive feedback metrics with ethical boundaries.
- Chart.js security event visualizations and filterable event tables.
- CyberFortress CTF challenges and user scoring integration.
- Complete project technical documentation and architecture overview.
